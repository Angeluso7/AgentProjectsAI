# Frontend - Plan Review AI Hybrid

Aplicación Single Page Application (SPA) construida en **React 18 + Vite + TypeScript**.

## Características
- **Dashboard de Memorias**: Monitoreo en tiempo real de las 4 memorias persistentes.
- **Visor de Planos Multicapa**: Visualización interactiva con capas toggleables para Viñetas, Símbolos detectados y Hallazgos.
- **Triage & Human-in-the-Loop**: Revisión, aceptación y descarte de hallazgos con retroalimentación a Active Learning.
- **Catálogo de Reglas y Normas**: Exploración de estándares y reglas determinísticas registradas.

## Ejecución Local
```bash
cd frontend
npm install
npm run dev
```
La aplicación se iniciará en `http://localhost:5173`.
