# template_memory (Memoria de Plantillas y Patrones)

Almacena modelos y descriptores geométricos reutilizables:
- **Viñetas (`title_block_templates`)**: Geometría y palabras ancla para extracción de metadatos.
- **Librerías de Símbolos (`symbol_libraries`)**: Catálogos de componentes gráficos por disciplina.
- **Esquemas de Tablas (`table_schema_templates`)**: Definición de columnas esperadas para cuadros de vanos y cargas.
- **Ontologías (`ontology_dictionaries`)**: Sinónimos y mapeos hacia conceptos canónicos.
