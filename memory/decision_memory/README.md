# decision_memory (Memoria de Decisiones y Precedentes)

Consolida la historia de auditorías y el aprendizaje supervisado:
- **Sesiones de Auditoría (`review_runs`)**: Registro de revisiones ejecutadas y estadísticas.
- **Hallazgos (`rule_findings`)**: Discrepancias detectadas clasificadas por severidad y confianza.
- **Evidencias (`finding_evidences`)**: Vínculos directos a recortes visuales y fragmentos de texto.
- **Feedback Humano (`human_feedbacks`)**: Aprobaciones, rechazos y correcciones (HITL).
- **Precedentes (`decision_precedents`)**: Excepciones autorizadas que evitan repetir falsos positivos en el mismo proyecto.
