# Datasets & Versionado

Datasets de entrenamiento y validación gestionados con **DVC (Data Version Control)**:
- `active_learning/`: Lotes de muestras seleccionadas por incertidumbre o feedback humano para reetiquetado.
- `layout/`: Anotaciones de macro-regiones de planos (Viñetas, Dibujos, Cuadros).
- `symbols/`: Datasets en formato COCO / YOLO de simbología arquitectónica y de ingeniería.
